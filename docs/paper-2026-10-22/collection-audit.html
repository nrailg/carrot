可复现证据

  • source-manifest.json 给出来源 URL、落盘路径、日期、解压后的 UTF-8 快照字节数和 SHA-256。源快照以 gzip 压缩，collect.py 可直接复用，无需重新联网。
  • collection-audit.json 记录去重、跨来源 ID 差异与摘要 / 作者覆盖。
  • screening-stats.json 保存会议级筛选与多标签统计；review-overrides.json 保存人工复核覆盖。
  • validation.json 核对唯一 ID、官方名册 ID 集合、分类子集、作者 / 摘要覆盖、Markdown 行数、来源校验和、内部链接、离线页面内嵌数据及 JavaScript 语法。
