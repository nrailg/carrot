## 阅读时常见的几个词

| 术语 | 本文中的含义 |
|---|---|
| 策略 | 根据当前观察决定下一步动作的模型或规则。 |
| 示教与行为克隆（BC） | 示教是人提供的任务执行样本；行为克隆用这些样本学习在类似观察下采取类似动作。 |
| 视觉—语言—动作模型（VLA） | 同时接收图像和文字指令，并产生机器人动作的模型。 |
| 强化学习（RL） | 通过尝试动作、获得反馈，再调整策略的学习方式；反馈常被表示为奖励。 |
| 世界模型 | 预测动作执行后环境或机器人状态如何变化的模型。预测准确不自动意味着能据此规划出成功动作。 |
| 闭环执行 | 执行后重新观察，再调整下一步动作；与一次生成整段动作后不再修正相对应。 |
| 潜表示 | 模型把图像或状态压缩成的内部特征，用来预测、比较或规划。它未必直接对应可解释的物理量。 |
| 模型预测控制（MPC） | 反复预测一段时间内候选动作的结果，选择较好的方案，执行其中前一部分后再观察和重新规划。 |

## 分类阅读

子问题与解决路线是主代理对本轮摘要的归纳，并非互斥的正式二级标签。代表论文用于说明路线，不表示质量排名；每篇代表论文均重新核读证据。

### 数据与监督成本

机器人学习往往需要人反复示范、纠错或标注。这里关注的核心是：在同样的人力预算下，怎样得到更有用的训练数据？具体包括少量示教怎么扩充、失败经验是否值得保留，以及哪些外部视频或合成数据真正有帮助。

一类方法改变采集方式，优先补充机器人容易失败的情况；另一类方法从已有数据中挑选互补样本，减少重复。还有方法借助物理规律、视频重建或仿真生成监督，降低人工标注需求。阅读时要把“少做示教”和“少花总成本”分开：预训练、自动交互和环境重置也可能很昂贵。

#### [DINS-IO: Learned Inertial Odometry via Differentiable INS Consistency](https://arxiv.org/abs/2607.20232)

**要解决什么问题**

训练一个根据惯性传感器读数估计运动的模型，通常要收集大量精确的位置标签，告诉模型设备当时实际移动到了哪里。这些标签依赖动作捕捉或其他定位系统，采集成本高。论文希望先从没有位置标签的传感数据中学习，再用少量标签把预测校准到真实速度。

**具体怎么做**

DINS-IO先读取惯性测量单元的数据，也就是设备测得的加速度和转动信息，让网络连续预测设备自身坐标系中的速度。训练时利用一个物理关系检查预测：速度的变化应当与测得的加速度相符。由于每段数据的初始速度未知、加速度传感器也有系统偏差，方法把这些未知量纳入计算，在连续的小段数据中求出最符合这个关系的解，再把剩余的不一致程度作为训练反馈。这样，第一阶段不需要精确位置标签。最后用少量带标签轨迹校准实际速度，只训练少量附加参数（LoRA），无需重新调整整个网络。

**结果能说明什么**

自监督阶段只学习运动一致性，得到准确的实际速度仍需要少量标签校准。摘要报告标准基准上的结果，未明确给出机器人部署实验。

#### [DISEIL: Demonstration Distillation for Sample-Efficient Imitation Learning](https://arxiv.org/abs/2609.08123)

**要解决什么问题**

交互模仿学习允许机器人先练习，再在出错时请专家示范，但已有方法主要决定何时打断机器人。究竟该优先纠正哪类失败、让专家从哪个状态开始，往往由碰巧触发中断的那次尝试决定，因而可能浪费有限的示范预算。

**具体怎么做**

DISEIL先找出每次失败中策略第一次变得不可靠的时刻，并用几何特征描述当时的情况。随后把相似失败归为反复出现的失败类型，从中选择需要补充示范的行为。视觉语言模型和语言模型据此写出下一次示范请求，任务约束库再检查请求是否可执行，避免先花费专家时间才发现要求不合理。这里模型改变的是向专家索取的数据，而非直接生成机器人动作。

**结果能说明什么**

实验限于五项仿真任务，专家大多由脚本实现，且每次只处理一轮练习结果。它尚未证明能长期跟踪示范覆盖范围或按真实人类教师的工作成本安排请求。

#### [Mulligan: Performance-Guided Data Collection for Efficient On-Robot Learning](https://arxiv.org/abs/2610.05882)

**要解决什么问题**

在需要精确操作且物体位置变化较大的任务中，策略的失败可能集中在少数初始摆放状态。均匀选择练习起点会让操作员反复监督机器人已经掌握的情况，而只模仿成功动作又会丢掉失败尝试中的学习信息。

**具体怎么做**

Mulligan把每轮从哪里开始练习也纳入数据收集决策，优先安排先前失败过和还没有尝试过的初始状态。机器人执行时仍由操作员摆放物体，并在需要时接管，因此有限的监督回合更多用于补足策略薄弱处。方法还用包括失败在内的全部数据训练价值函数，即估计动作能带来多好结果的模型，再结合交互模仿学习来选择动作。在相同采集预算下，这两项改动分别改善练习机会的分配和已采数据的利用。

**结果能说明什么**

论文在三项实机任务和两项仿真任务上验证；实机最终成功率提高10至34个百分点是与价值动作选择联合后的结果。收集回合98%的完成率包含操作员干预，不能当作机器人独立执行的成功率。

#### [From Sample to Subset Construction: Coverage-Aware Curation of Robot Demonstrations](https://neurips.cc/virtual/2026/poster/150964)

**要解决什么问题**

示范数量增多并不一定让机器人学得更好：重复轨迹可能占满预算，而少见、甚至不够完美的片段却包含关键动作转换。若逐条给轨迹或片段打分，就无法判断它对已经保留的数据还补充了多少新内容。

**具体怎么做**

PROSE在固定预算下逐步构建示范子集，每加入一份数据，都重新考虑它相对于已选集合的新增价值。评分同时考虑数据对机器人实际执行回报的影响、运动是否可靠，以及它是否覆盖已选数据没有覆盖的情况。完整轨迹和更细的动作片段都可以参与选择，使关键转折不必依附于整条高分轨迹才有机会被保留。这种集合层面的选择机制旨在减少冗余，同时留下对任务有用的稀少经验。

**结果能说明什么**

结果来自三项Robomimic仿真任务和三项Franka实机任务，消融实验把主要收益归因于覆盖项。运动可靠性只是联合评分的一部分，不能把该方法概括为删除所有不完美或失败示范。

#### [Splat2Act: From Captured Scenes to Personalized VLA Manipulation](https://arxiv.org/abs/2610.13945)

**要解决什么问题**

通用操作策略进入用户的家或办公室后，可能无法直接适应当地的货架、桌面和个人物体。逐个场景采集实机示范代价很高，而仅重建单张桌面的仿真方法又难覆盖建筑尺度的多处操作位置。

**具体怎么做**

Splat2Act以手机扫描和用户物体照片为输入，建立既能逼真渲染、又包含碰撞几何的室内数字场景。系统自动寻找桌面及其他可放置物体的位置，生成可行的拾取任务，再让能访问仿真内部信息的教师生成成功示范。它用这些示范分两阶段微调已有的视觉、语言与动作策略：先适应公共物体，再针对部署场景中的用户物体做个性化训练。这样，人主要负责捕获场景和物体，场景专属动作示范由仿真生成。

**结果能说明什么**

最强策略的62.5%是目标场景聚合成功率；12项任务子集的实机和仿真成功率分别为63.9%与66.7%，评测口径不同。减少人工示范不意味着取消教师，训练仍依赖能访问仿真内部信息的教师。

### 泛化迁移

机器人在训练桌面上能完成任务，换物体、相机位置或机器人后却可能失败。本类研究希望找出哪些知识可以保留，哪些部分必须重新适配；其中也包括把已经学会的单臂技能组合成新的双臂任务。

常见做法是让策略更多依赖接触几何、物体关系或任务指令等可迁移信息，减少对背景外观和固定轨迹的依赖。另一些方法显式处理仿真与真实物理行为的差异，或把通用技能与机器人专属控制分开。关键要看泛化究竟允许哪些变化，以及是否需要新数据或微调。

#### [World Translation: Minimizing Sim-to-Real Gap with Backward Dynamics Extraction and Unpaired Domain Translation](https://arxiv.org/abs/2607.18154)

**要解决什么问题**

仿真策略迁移到实机时，真实动力学模型需要解释同一观测为何会产生不同的后续运动。已有方法常依靠过去的观测恢复隐藏因素，但突然接触等事件可能事先没有线索，使仅从历史向前预测的方法无法消除歧义。

**具体怎么做**

World Translation利用已经发生的一次状态转移，反向提取造成这次变化的隐藏动力学信息。它再把这种信息在仿真与真实世界之间做无需一一配对样本的转换，目标是保留运动变化的内容，同时改变所属环境的特征。这一设计结合了仿真器给出确定变化的能力和学习模型贴近真实运动的能力，绕开必须先从历史观测猜中全部隐藏因素的要求。论文在多种机器人平台比较动力学建模，并用Go2四足机器人检验策略迁移。

**结果能说明什么**

收益在隐藏因素无法从历史恢复的条件下最明显；该结论来自论文所测平台与转移条件。摘要没有展开反向提取和跨域转换的具体实现，不能据此断言它能恢复任意隐藏物理参数。

#### [One Demonstration, Many Objects: Generalizing Manipulation via Local Contact Geometry](https://arxiv.org/abs/2609.01938)

**要解决什么问题**

灵巧手的大规模机器人示范难以采集，因此利用人类示范训练是有吸引力的替代方案。但已有仿真到实机强化学习方法可能缺少鼓励精确接触的奖励，也容易在物体形状或其他属性改变后失效。

**具体怎么做**

DemoMimic利用人类示范提供物体交互与接触方式的先验，把策略关注点放在接触点附近的局部几何上。训练时使用以接触为中心的奖励，明确鼓励手指形成准确的接触关系，而不只追求大致完成动作。当不同物体保留相同的局部接触结构时，同一策略便可以沿用相似的接触方式，应对整体形状、尺寸、质量和摩擦的变化。其迁移依据因此是接触区域的相似性，而非整件物体完全相同。

**结果能说明什么**

泛化以局部接触结构保持为条件，不能推广为任意新物体都可直接操作。摘要报告四项任务、16个物体和两种手部形态上的71%实机成功率。

#### [Impedance Cloning: Learning Equilibrium Point Parameters for Contact-Rich Manipulation](https://arxiv.org/abs/2609.30842)

**要解决什么问题**

擦拭、抓取等持续接触操作需要在表面位置或形状改变时仍保持合适的作用力。直接复现示范轨迹，只学到了原场景中运动的结果，遇到几何偏移时可能失去接触，或无法被动吸收误差。

**具体怎么做**

Impedance Cloning改为学习刚度和平衡点：前者决定受到偏移时抵抗多强，后者表示机器人希望趋向的位置。方法从双边遥操作示范中用粒子滤波估计这些参数，即在多组候选参数间根据观测更新可信程度，而不要求力或力矩传感器。策略模仿这些生成运动的参数，使实际动作可以随接触表面变化，而非严格贴着原轨迹走。论文在擦拭、杯子搬运和抓取中检验这种表示，并比较不同动作空间与策略骨干。

**结果能说明什么**

几何适应能力有范围：擦拭实验中，表面下降超过给定区间后接触力仍会逐渐降低。两台CRANE-X7机械臂上的结果支持所测操作条件，不能据此保证任意表面或接触任务的力稳定性。

#### [When Listening Becomes Easier: Scrubbing Visual Cues for Shortcut-Free VLAs](https://arxiv.org/abs/2610.10912)

**要解决什么问题**

机器人示范多样性有限时，视觉、语言与动作模型可能把背景或视角误当成任务线索，忽略真正的语言指令。补采足够多的场景代价高，而且不同模型骨干纠正这种错误关联的能力并不一致。

**具体怎么做**

论文先用动作裕量这一内部表示指标诊断捷径倾向，无需实际运行策略便可分析模型行为。逐层分析发现，无关视觉线索很早就进入动作表示，而后续网络是否能用语言信息纠正它，因模型而异。作者据此提出task scrubbing，用域对抗训练减少模型利用视觉捷径的倾向，也就是训练模型降低对这类无关视觉差别的依赖。其目标是让动作更多服从语言任务，从而在背景或视角变化后仍可靠执行。

**结果能说明什么**

摘要支持多种模型及仿真、实机条件下的鲁棒性提升，但未展开对抗训练各分支的目标和构造。结果称经常能消除所测视觉捷径，不能解释为对所有无关视觉因素都有保证。

#### [SkillVLA: Tackling Combinatorial Diversity in Dual-Arm Manipulation via Skill Reuse](https://arxiv.org/html/2603.03836v1)

**要解决什么问题**

双臂操作的难点不仅是学会左右手各自的动作，还在于同一批单臂技能能组成许多不同任务。若模型把左右动作紧密纠缠在一起，学过的单臂技能就难以重新配对，可能需要为每种组合重新收集数据。

**具体怎么做**

SkillVLA先由冻结的高层视觉语言模型分别写出两只手要执行的技能，再交给彼此解耦的低层模型和动作专家执行。两臂并非始终互不交流：合作估计器会判断何时需要协同，并控制专家之间是否交换信息。训练时比较开启和关闭通信后的模仿误差，学习哪些交流确实有帮助，同时用先验、时间平滑和鼓励谨慎通信的约束稳定决策。这样，独立动作可以复用到新的左右配对中，需要合作时又能临时建立联系。

**结果能说明什么**

技能组合评测中成功率由0%提高到51%，仍有大量组合未成功。通信由门控按需开放，因此该方法的复用机制不能理解为彻底禁止双臂交互。

### 感知状态

机器人必须知道物体在哪里、是否接触、环境发生了什么变化，但相机可能被遮挡，深度可能不准，传感器也可能暂时不可用。这里研究如何从不完整、有噪声的观察中，得到足以支持行动的状态估计。

方法包括融合相机、惯性和触觉等信号，用几何关系校正学习模型，以及利用历史观察维持地图和物体记忆。有些方法还估计“自己有多不确定”，据此决定什么时候需要重新观察。感知指标提高与实际任务成功率提高需要分别验证。

#### [OASIS-Map: Object-Level Change Detection in Multi-Session Mapping using Semantic Correspondence Matching](https://arxiv.org/abs/2607.14899)

**要解决什么问题**

机器人长期巡检时，两次访问之间可能有物体被移动、替换、搬入或移走，旧地图很快就会过时。即使知道类别或几何相似，也很难在遮挡、局部视角和分割误差下判断这次看到的是否还是上次那个物体。

**具体怎么做**

OASIS-Map在不同访问的图像之间建立稠密的局部图块语义对应，即比较许多小区域的内容是否相互匹配。系统用这些对应发现哪些位置发生变化，并在重新观察环境时逐步关联物体。地图因此不仅记录物体在哪里，还持续维护物体跨时间的联系，使场景变化与物体身份关联可以一起更新。论文在室内物体重排、停车场相似车辆替换和室外市场变化中检验这一机制。

**结果能说明什么**

停车场替换检测的F1为0.783，3RScan中移动物体关联的F1为0.667，两者是不同任务指标。这些结果表明仍存在漏检、误检或关联错误，不能视为长期物体身份完全可靠。

#### [VIDAR: Visual-Inertial Dense Alignment and Reconstruction via a Geometric Foundation Model](https://arxiv.org/abs/2607.17171)

**要解决什么问题**

单张相机图像的几何基础模型能预测密集场景结构，却往往不能稳定确定真实尺寸。把多帧预测融合起来时，尺度和坐标不一致又会妨碍形成统一的三维地图。

**具体怎么做**

VIDAR把视觉惯性里程计与Depth Anything 3几何模型结合起来：前者利用相机和惯性数据估计相机位置、真实尺度及统一世界坐标。后者提供细致的局部几何，利用这些位置与尺度信息把不同时刻的预测对齐，再融合为全局重建。论文比较直接把相机位姿输入几何模型，以及先预测再单独对齐两条路线。二者都用具有实际尺度的运动估计，补足单目几何预测缺少稳定尺度的问题。

**结果能说明什么**

验证来自EuRoC与TUM RGB-D数据集；EuRoC上解耦方案的重建指标优于位姿条件方案。报告的结果支持这些数据集中的度量重建，未直接证明任意场景中的导航或操作收益。

#### [PredTac: Learning Contact-Rich Manipulation with Predicted Touch](https://arxiv.org/abs/2609.15198)

**要解决什么问题**

触觉能帮助机器人判断接触状态，但增加实体触觉传感器也会带来硬件、标定、同步和维护成本。只依赖视觉的策略又可能缺少接触细节，难以可靠完成插接、拔出或旋转等任务。

**具体怎么做**

PredTac先利用带触觉标签的数据，训练一个从截至当前可见的图像和机器人状态推断触觉状态的预测器。随后把预测出的接触信息作为明确的中间输入，交给下游动作策略学习和执行。这样，下游策略不必在每次训练或运行时都接入实测触觉，仍能利用预测器学到的接触知识。论文还固定策略并改变预测接触的空间布局，检验收益是否确实依赖接触内容，而不只是多了一组数值。

**结果能说明什么**

触觉预测器的训练仍需要触觉监督，节省的是下游策略训练和执行时的实测触觉输入。三项实机任务平均成功率为70.0%，接近实测触觉策略的72.2%，并不意味着预测触觉在所有条件下等同真实触觉。

#### [Acting from Belief, Looking When Needed: A Bayesian Spatial World Model for Navigation under Intermittent Perception](https://arxiv.org/abs/2610.11591)

**要解决什么问题**

导航通常依赖持续、高频的环境观测，但共享相机可能临时被其他任务占用，导致导航信息中断。机器人既要在看不见新信息时继续行动，也要判断什么时候已有认识已经不够可靠、必须重新观察。

**具体怎么做**

ALONE维护一个包含空间结构及不确定性的内部认识，并根据已经执行的动作推演它如何变化。它用学到的常见几何结构补充尚未观测的区域，获得新观测后再修正估计。模型向运动规划器提供空间估计和可靠性地图，后者表达各区域估计有多可信。只有当可靠性不足妨碍导航、且新观测预计能改善相关区域的信息时，系统才请求新的深度图，其余时间继续根据内部估计行动。

**结果能说明什么**

仿真中的0.9%与1.3%观测比例，是成功试次中需要新深度观测的决策步占比的中位数。实机验证只有10次室内飞行，不能把该比例或全部成功的结果推广到任意环境。

### 指令理解与任务推理

听懂一句话不等于知道该操作哪个物体、朝哪个方向移动，或先做哪一步。这里关注指令如何变成明确、可执行的目标，以及机器人遇到歧义时何时应该提问或换个角度观察。

一些方法把指令转换成对象关系、程序或形式化规则，再交给行动模块；另一些方法保留多种可能解释，用新观察或用户澄清缩小范围。也有工作研究同一个意思换一种说法为何会导致不同动作，并在输入端改写指令以减轻这种敏感性。

#### [Logic-VLA: A Temporal Logic Conditioned Vision-Language-Action Model](https://arxiv.org/abs/2608.20556)

**要解决什么问题**

自然语言可以说明导航目标，却不总能精确表达必须何时到达、避开什么区域等时空要求。一般视觉、语言与动作模型即使完成了主任务，也可能违反这些额外约束，并且难以随新规范调整行为。

**具体怎么做**

Logic-VLA在执行时额外接收信号时序逻辑规范，用形式化表达式明确随时间成立的条件。预训练的编码器把规范语法图转为模型能利用的表示，先用满足规范的示范监督微调策略。随后再比较相互匹配的满足与违反规范的执行轨迹，通过偏好优化提高前者的相对倾向。这样的两阶段训练旨在让同一策略适应不同形式要求，同时尽量保留原自然语言任务的完成能力。

**结果能说明什么**

结果来自四旋翼闭环导航仿真，也测试了未见过的逻辑公式。规范满足率提高24.8至40.7个百分点属于经验评测提升，不构成形式安全保证。

#### [GRAVA: Grounded Reasoning-to-Action Representation and Learning for Autonomous Driving](https://arxiv.org/abs/2609.15169)

**要解决什么问题**

驾驶模型在行动前生成推理，并不意味着推理确实对应眼前的物理证据。若中间解释与图像中的对象、车辆状态和最终轨迹联系松散，模型可能说出合理理由，却无法把关键对象关系保留到可执行行为中。

**具体怎么做**

GRAVA把与动作有关的语言指代连接到图像区域和以自车为中心的物理状态，再用带类型的图描述对象互动与驾驶决策。这个结构以轨迹为锚点，并被转写为模型能够连续生成的推理序列。单个视觉语言模型先生成这些有证据对应的推理，再生成紧凑的规划动作，由固定解码过程转换为连续行驶轨迹。训练数据同时从场景向前建立对象联系、从轨迹向后确定相关证据，并通过预训练、模仿和强化学习逐步学习推理到动作的连接。

**结果能说明什么**

主要结果来自NAVSIM和内部长尾基准，摘要未报告道路实车部署。内部长尾基准上的对象遵从性与驾驶得分提升，不能直接解释为公开道路安全性的保证。

#### [Active Perception for Embodied Disambiguation](https://arxiv.org/abs/2608.13605)

**要解决什么问题**

机器人听不清指令所指对象时，原因可能是用户意图不明确，也可能只是当前视角缺少关键证据。已有交互消歧方法主要向用户追问，但遮挡、看不清文字或尚未看到目标等问题，需要机器人先改变观察方式。

**具体怎么做**

该框架以主动观察作为获取信息的主要手段，通过改变观察来寻找区分候选目标的物理证据。视觉语言模型持续综合已积累的图像和交互信息，决定继续观察、请求用户澄清，还是完成目标选择。新的视角可能直接消除歧义，也可能读出物体名称、标签或属性，帮助之后提出更有效的澄清问题。这样，补足视觉证据与询问用户意图被放到同一个决策过程中。

**结果能说明什么**

摘要报告实机实验支持这一流程，但未给出量化成功率或各类歧义的覆盖范围。其结论是主动观察与澄清可以结合，不能据此保证所有目标歧义都可解决。

#### [RefGuard: Identity-Aware Language-Guided Robot Manipulation via Joint Target-Anchor-Frame Grounding](https://arxiv.org/abs/2609.06221)

**要解决什么问题**

面对多个相似物体时，机器人可能完成了几何上正确的动作，却操作了用户没有指向的那一件。问题还涉及作为定位依据的参照物，以及“左边”等词采用谁的参考方向；过早确定其中一项，会把剩余歧义悄悄带进执行。

**具体怎么做**

RefGuard从彩色与深度图像建立以物体为中心的场景图，把不随观察方向改变的几何关系与依赖参考系的方向关系分开。系统同时保留目标、参照物和参考系多种组合的概率，而不是逐项提前选定唯一答案。决策模块根据这组联合判断，选择执行、向用户澄清、重新观察或中止。其作用是让目标身份上的不确定性保持可见，直到证据足以支持行动。

**结果能说明什么**

实机歧义压力测试中没有发生身份切换，但正确执行率为90.0%，两项指标并不相同。有限试验中没有观察到身份切换，不能视为对任意场景的零错误保证。

#### [Rephrase Before You Act: Characterizing and Mitigating Language Sensitivity in Vision-Language-Action Models](https://arxiv.org/abs/2610.10526)

**要解决什么问题**

视觉、语言与动作模型可能理解不了意思相近的两种说法，仅改一个词就使任务成功率大幅变化。即使用改写指令做过训练增强，这种敏感性仍可能存在，因此用户正常换一种表达也会影响执行。

**具体怎么做**

该方法先在少量训练任务上测试多种说法，收集哪些措辞更容易成功的证据。再让语言模型把这些规律整理成十至二十条明确的指令改写规则。部署时，每条新指令只按规则改写一次，再交给保持冻结的动作策略执行。由于措辞敏感性呈现可重复的规律，这种处理能在不重新训练策略的情况下，减少输入表达带来的性能波动。

**结果能说明什么**

规则需要预先进行任务与措辞评分，并非完全无需前期数据。留出任务上16%至27%的收益为相对提升；理想措辞搜索展示的上界也不能当作实际改写规则的收益。

### 长任务与记忆

任务变长以后，机器人可能忘记物体曾经放在哪里、重复已完成的步骤，或在动作阶段切换时出错。即使每一步预测看起来合理，整段行为也不一定持续接近最终目标。

研究路线包括把长任务拆成可复用技能，为物体和事件建立结构化记忆，以及让规划模型保留不同动作造成的未来差异。另一些方法专门处理动作块跨越阶段边界时的衔接。需要区分模型“看到了历史”和“确实利用历史完成任务”。

#### [ActSWM: Action-Sensitive World Models for Long-Horizon Planning in Open-World Games](https://arxiv.org/abs/2607.26712)

**要解决什么问题**

世界模型常在压缩后的状态空间里预测未来，再据此挑选动作。但预测看起来接近真实未来，不代表模型能区分不同动作的后果；如果几种动作都预测出相似未来，规划器就失去了选择依据。

**具体怎么做**

ActSWM从状态和候选动作序列出发，预测各自的未来状态。它要求不同动作引起的未来保持可区分，并要求能够从相邻状态的变化中恢复对应动作。训练把这种动作敏感性直接作为未来展开的约束，而不只是附加一个动作预测任务。这样设计的用意是让长期预测始终保留“做什么会改变什么”的信息，供滚动规划反复选择和执行动作。

**结果能说明什么**

证据来自Minecraft闭环规划、预测漂移分析及跨游戏动作恢复，摘要未报告机器人实验；游戏中的收益不能直接视为实体控制收益。

#### [TRACT: Temporally Routed Action Chunks with Chronological Phase Authority for Contact-Rich Manipulation](https://arxiv.org/abs/2607.29285)

**要解决什么问题**

机器人一次预测一段未来动作时，这段动作可能跨过“擦拭结束、开始下一步”等任务阶段边界。如果整段都按当前阶段生成，后半段就可能使用错误的阶段条件；接触造成的运动受阻还可能让执行停滞。

**具体怎么做**

TRACT把未来动作段表示为当前阶段，以及从当前阶段切换到下一阶段的一个边界。它用任务阶段图约束阶段推进顺序，并用随时间单调变化的边界分布，把不同位置的动作预测分配给相应阶段的生成路径。执行接触动作时，系统还比较策略希望产生的运动与随后实际出现的响应。若沿目标方向的响应不足，就逐步累积机械臂补偿，并在确认恢复后减小补偿。前两项针对跨阶段预测错配，后一项则针对接触受阻后的持续停滞。

**结果能说明什么**

结果来自六种实机配置、各十次试验；作者明确指出，整套生成方案的对照没有单独隔离阶段路由的贡献。

#### [OCC4M: Object-Centric 4D Memory for Spatiotemporal Reasoning in Long-Horizon Manipulation](https://arxiv.org/abs/2609.28798)

**要解决什么问题**

长任务常要记住当前画面之外的事实，例如物体消失前的位置、移动后的身份，以及某个容器里装过什么。直接把历史图像交给视觉语言模型，并不保证它能把跨时间、跨视角的物体关系对应起来。

**具体怎么做**

OCC4M以物体为单位建立持续记忆，将历次观察中的物体轨迹放进共同的世界坐标系。记忆显式保存时间、运动和包含关系，让“物体在哪里”和“容器里有什么”成为可查询的信息。视觉语言模型读取这些结构化记录，选择当前可执行的目标。底层执行器只负责执行所选目标，无需自行读取完整历史；这一分工把长期状态推理集中在记忆层。

**结果能说明什么**

仿真中的记忆成功率与端到端成功率是不同指标；20次固定相机实机试验中的85%联合记忆准确率，也不等于45%的完整两阶段任务完成率。

#### [Long-WAM: Scaling the Context of World-Action Models](https://arxiv.org/abs/2610.10528)

**要解决什么问题**

实时操作既需要历史画面来判断运动和任务进度，又不能因处理历史而延迟出手。仅仅扩大输入历史也未必有效，因为模型即使能看到更多过去，也可能没有学会利用它预测未来。

**具体怎么做**

Long-WAM先用没有动作标签的机器人视频和第一视角视频，训练模型按时间顺序从过去预测未来。随后将它适配为同时预测世界变化和机器人动作的模型，并保留这种从历史到未来的预测结构。运行时采用流式观察编码、异步执行及针对硬件的加速，使长历史处理能配合实时动作生成。其针对问题的依据是：摘要中的对照发现，按时间顺序预训练的模型能从更长历史获益，而双向预训练初始化没有出现同样的净收益。

**结果能说明什么**

速度和任务成功率对应特定硬件、平台及测试设置；动态叠杯的95%成功率不能代表所有长任务都达到这一水平。

#### [PRISM: Primitive Routing via In-context Skill Mixing for Lifelong VLA](https://neurips.cc/virtual/2026/poster/154388)

**要解决什么问题**

机器人学习新任务时，把所有技能都写进同一组共享参数，可能损害已经学会的能力。长任务还要求模型随任务阶段调用不同旧技能，仅仅保留参数并不能自动解决技能组合。

**具体怎么做**

PRISM为每类技能保存一个专用的低秩动作适配器，也就是只增加少量参数的动作专家，并把它们组成原语库。执行时，视觉语言条件下的路由器读取已有上下文判断进度，为每个未来动作段混合相应专家。路由器的训练标签由动作数据按确定规则生成，用来指导何时调用哪些技能。组合任务训练会更新视觉编码、语言适配器和路由器，但保持所有动作专家冻结。这样的参数组织使旧动作专家得到保留，同时给跨阶段调用提供明确机制。

**结果能说明什么**

冻结保证的是技能专家参数保留，并不构成所有行为绝不遗忘的理论保证，因为视觉和语言模块仍会变化；RoboCasa365组合任务成功率为20%。

### 动作与物理交互

操作的难点常在实际接触中出现：力太大会损坏物体，力太小会滑落，柔软物体还会随动作改变形状。移动机器人也面临类似问题，计划的路径必须符合真实动力学与执行器限制。

一类方法将几何、力和动力学知识加入策略或规划器；另一类方法学习更合适的动作表示，例如同时预测位置与刚度。还有工作预测多个候选动作会造成什么结果，再选择并执行其中一个。这里关注预测信息如何真正用于控制。

#### [Reconstructing Is Not Acting: Action-Centric Latent Dynamics Modeling](https://arxiv.org/abs/2609.15189)

**要解决什么问题**

从无动作标签的视频中学习时，模型通常先推断一个隐藏动作，再用它重建未来画面。但画面重建误差低，不一定说明动作表示有用：模型可能把外观变化当动作，也可能只靠当前状态猜未来而忽略动作。

**具体怎么做**

ACT-LAM针对动作的提取和使用分别改造模型。提取端用可学习的动作查询和门控聚合，从前后画面变化中选择与动作有关的线索，减少无关外观的干扰。预测端将隐藏动作转换成动作令牌，使它们在多层计算中持续与状态表示交互。这样设计的意图是既让表示更像真实的动作变化，也让未来预测真正受这些动作影响。模型还简化特征处理，将容量集中在状态转移建模上。

**结果能说明什么**

摘要中的证据是机器人数据集及视觉规划基准，包含聚合成功率提高7.6%的结果；它不等于在所有实体操作场景中都有同等收益。

#### [From Prediction to Decision: World-Model-Guided Action Selection for Continuous Pile Excavation](https://arxiv.org/abs/2609.15382)

**要解决什么问题**

装载机每铲一次都会改变料堆，下一铲的可行位置和收益也随之变化。实际系统不仅要预测地形变化，还要在有限时间内比较候选动作，才能把预测质量转化为更少的清理铲次。

**具体怎么做**

该世界动作模型从当前料堆地形出发，先生成多个候选铲挖动作，再剔除几何上不可行的候选。它为剩余动作同时预测地形的增减变化和装载量，选择预测装载量最大的动作执行。完成一铲后，系统重新观察地形并重复规划。这样的闭环让每次决策都适应上一铲造成的变化，而装载量排序提供了直接的动作选择依据。

**结果能说明什么**

减少平均铲次17.1%的决策收益来自仿真配对对照；全尺寸装载机实验支持完整闭环可行性，不能把二者混作同一项实机量化结果。

#### [An Efficient Algorithm for Minimum-Pressure Growth Planning of Vine Robots](https://arxiv.org/abs/2609.18070)

**要解决什么问题**

藤蔓式软机器人靠尖端不断伸长穿过障碍，但能绕过去的路径未必能安全长出来。已有规划若忽略路径所需的生长压力，就可能选到压力过高、使机器人爆裂的路线。

**具体怎么做**

方法以障碍物几何为输入，先建立任意形状藤蔓机器人所需生长压力的方程。作者据此证明，存在一条最低压力路径，可以由直线段组成，而且只需在障碍物上的特定点转弯。这个性质把连续路径搜索缩减为一个边权随推进变化的最短路问题。随后用改进的Dijkstra最短路算法求解，使规划直接围绕压力而非仅围绕路径长度展开。

**结果能说明什么**

全局最优保证适用于二维；三维结果是离散近似，其误差随离散参数趋零而消失，不能称作任意离散精度下的三维全局最优。

#### [Imp-ACT: Adaptive Impedance Control and Action Chunking with Transformers to Learn Contact-Rich Manipulation from Demonstrations](https://arxiv.org/abs/2609.31225)

**要解决什么问题**

擦拭和插接等接触任务既要沿目标方向准确运动，也要能顺应环境，避免横向挤压和力振荡。但许多视觉动作策略只预测运动，机器人的软硬程度仍由固定控制参数决定，难以兼顾两者。

**具体怎么做**

Imp-ACT在遥操作采集示范时，就让控制器自动调整运动方向上的刚度，同时在垂直方向保持柔顺。这里的刚度决定机器人偏离目标位置时会多强地拉回，柔顺则允许它随接触适当让步。系统把实际使用的刚度与图像、运动命令一起记录，形成运动和接触方式相匹配的示范。训练后的策略根据视觉、机器人自身状态及力和力矩观察，一次预测一段末端位姿、夹爪动作和运动方向刚度。这样的动作输出能同时规定“往哪里动”和“以多硬的方式动”。

**结果能说明什么**

验证范围是擦拭和插头插入任务；相对固定刚度基线的力振荡、横向力改善分别对应各自任务，不能合并成通用接触收益。

### 自主学习与持续改进

示教结束后，机器人能否通过自己的尝试持续提高？困难包括试错昂贵、成功反馈稀少、失败后需要人来复位，以及新学习可能覆盖原本已经掌握的技能。

方法通常把已有策略、价值估计和在线交互结合起来，优先练习薄弱环节。为了减少值守，也有系统学习恢复动作，或利用一次示教提供自动纠错参考。所谓“自主学习”仍可能需要人设定目标、恢复点、奖励或安全条件，这些成本应单独记录。

#### [RoboClaw: An Agentic Framework for Scalable Long-Horizon Robotic Tasks](https://arxiv.org/abs/2603.11558)

**要解决什么问题**

机器人数据采集、策略学习和部署往往彼此分开，导致训练时反复依赖人工重置。到了长任务执行阶段，多种已学策略又可能因上下文不一致而衔接不稳。

**具体怎么做**

RoboClaw让同一个视觉语言模型驱动的控制器贯穿采集、学习和执行。它把前向操作行为与反向恢复动作配对，让机器人执行操作后能通过恢复动作回到可继续采集的状态。这样的自重置循环支持持续收集当前策略产生的数据，并迭代改进策略。部署时，控制器继续使用一致的语义上下文，动态调度学到的操作原语来完成长任务。其设计把减少重置人力与改善多策略衔接放在同一个流程中处理。

**结果能说明什么**

实机结果支持减少人力和提高所测长任务成功率，但流程仍以最少人工介入为目标，不能称为完全无人训练与部署。

#### [One Demonstration Is Enough for Real-World Robotic Reinforcement Learning](https://arxiv.org/abs/2607.01651)

**要解决什么问题**

实体机器人强化学习的数据采集昂贵，探索时还容易偏离可行轨迹。已有示范辅助方法常需大量示范，或要求人一直在场干预，限制了少量示范条件下的自动训练。

**具体怎么做**

AutoSERL以一次示范为参考，通过滑动窗口干预持续引导探索，减少不安全偏离和局部最优。检测到失败状态后，系统利用预先定义的轨迹恢复点自动纠正，使训练得以继续。当策略已经能独立完成任务时，终止判据会关闭指导，保留后续自主探索空间。三种机制分别处理训练中的引导、失败后的恢复和成熟后的退出，让原本持续依赖人的干预过程自动化。

**结果能说明什么**

一次示范不等于零人工设置，恢复机制仍使用预定义恢复点；100%成功率指所测插入任务，实验总体为两种平台上的六项接触任务。

#### [From Pretraining to Proficiency: Real-World Subtask RL for Long-Horizon Manipulation with Minimal Human Intervention](https://arxiv.org/abs/2609.21788)

**要解决什么问题**

预训练策略可能已经会完成长任务的大部分步骤，却总在少数关键子任务上失败。重采整段示范会重复大量已会的行为，而只用任务结束时的稀疏奖励，又很难告诉策略该改进哪一步。

**具体怎么做**

PARTS保持预训练策略冻结，让它持续提供基础动作。针对人类识别的瓶颈，代理生成的选择器决定何时启用额外修正，成功验证器则为子任务结果提供局部奖励。强化学习训练的是叠加在基础动作上的残差修正，因此练习集中在难点。训练交替进行在线学习和提高成功经验权重的再训练，再把更新后的修正策略部署回去采集经验。局部成功即使尚未带来全任务成功，也能成为学习信号。

**结果能说明什么**

人类仍需在初始化时识别瓶颈，并按需进行物理复位；摘要中数十分钟的平均实机训练时间对应所测任务，不代表完全无人或通用成本保证。

#### [When Life Gives You BC, Make Q-functions: Extracting Q-values from Behavior Cloning for On-Robot Reinforcement Learning](https://arxiv.org/abs/2605.05172)

**要解决什么问题**

模仿示范学到的行为克隆策略缺少自行判断如何在线改进的机制。直接转入在线强化学习时，新的交互数据分布又可能使策略覆盖原先已经学好的动作。

**具体怎么做**

Q2RL先通过少量环境交互，为行为克隆策略提取动作价值估计，也就是估计某个动作对后续累计收益有多好。随后，系统比较行为克隆策略与在线强化学习策略各自候选动作的价值，选择其中一个执行。由此得到的交互样本继续用于训练强化学习策略。这个选择机制的用意是在探索新动作的同时，仍有依据地保留示范中已经有效的行为。

**结果能说明什么**

1至2小时在线交互、最高100%成功率对应论文所测的精细接触操作任务，不能推广为所有任务的训练预算或成功率。

#### [EmbodiedRSI: Active Continual Robot Learning Through Hypothesis-Guided Co-Evolution](https://arxiv.org/abs/2610.10498)

**要解决什么问题**

机器人基础策略会因物体位置或指令变化而退化，直接收集大量数据再训练的成本很高。围绕模型修改程序和技能的智能体虽能适应，却可能把昂贵的机器人试验耗在缺少辨别价值的尝试上。

**具体怎么做**

EmbodiedRSI在快慢双系统中维护一个假设图，保存相互竞争的程序修改和技能修改方案。系统按信息价值选择物理试验，优先做那些能区分不同假设的交互。试验结果再指导程序与技能共同更新。慢系统还建立分层记忆，并根据记忆对后续快系统改进的奖励价值筛选内容。这样的循环把“下一次试什么”纳入学习过程，目的是让有限实体交互更有效地支持改进。

**结果能说明什么**

这里改进的是围绕基础策略的程序、技能和记忆，不能将其等同于基础模型本体预训练；实机71.3%总体成功率只覆盖所测任务。

### 安全、鲁棒与恢复

机器人不仅要完成任务，还要及时发现异常、限制损害，并在失败后恢复。这里要分开看三个问题：能否识别风险、能否阻止危险动作，以及干预之后是否真的比继续执行更好。

常见路线是监测执行与预测是否一致、校准模型的不确定性，或用约束控制器筛选动作。恢复方法则尝试退回可重试状态、修正剩余动作或重新规划。检测准确率、仿真中的少碰撞和带假设的安全证明，各自能支持的结论不同。

#### [Learning Robust Execution in Robotic Manipulation with Agentic Reinforcement Learning](https://arxiv.org/abs/2607.13818)

**要解决什么问题**

机器人长时间操作时，小误差可能逐渐累积，最终让执行偏离正常状态。视觉语言动作策略即使能泛化到不同任务，也常缺少明确机制来判断执行是否正在恶化，以及何时恢复。

**具体怎么做**

方法先用两种互补指标在运行时评价执行质量。高层策略读取近期执行历史，在少量执行模式之间作出选择，并通过强化学习学会调节执行过程。发现退化时，它触发恢复机制，将机器人带回先前经过的正常状态，再继续任务。学习重点因此落在何时切换模式和恢复，而不是重新学习所有底层动作。

**结果能说明什么**

摘要中的标准与扰动条件收益来自LIBERO基准，且报告的是最高改善幅度；未给出可推广到任意实体平台的稳定性保证。

#### [CheckVLA: Execution-Time Verification with Action-Conditioned World Model for Long-Horizon Mobile Manipulation](https://arxiv.org/abs/2607.26789)

**要解决什么问题**

视觉语言动作策略一次下发一段动作后，可能暂时不再接收高层视觉反馈，途中偏差便会被后续动作放大。下发时的置信度无法发现之后才发生的意外，而只看画面的异常分数又难以区分正常动作效果与真正偏差。

**具体怎么做**

CheckVLA用单独训练并冻结的世界模型，以已下发动作为条件，判断观察变化是否符合预期。经保形校准的风险阈值决定何时介入，并约束整次任务中首次多余介入的概率。超过阈值的程度还影响重写后的动作尾段保留原计划的力度。修复时，系统考虑推理延迟，只替换仍来得及下发的动作，并用事件触发的关键帧库保留先前进度。这样的校验与修复为动作段执行重新补上反馈。

**结果能说明什么**

结果来自RoboCasa365仿真；误报警校准针对整次任务中首次不必要介入，不应解释为任意情境下的整体安全保证。

#### [MAGMA-GEN: Validated Recovery Supervision from Ambiguous Failures via Counterfactual Re-Execution](https://arxiv.org/abs/2609.20056)

**要解决什么问题**

长任务失败后，很难判断是高层决策错了、观察不完整，还是决策正确但底层技能偶然执行失败。普通监督数据往往没有这些失败状态下的恢复动作，强化学习又受稀疏奖励和难以定位责任步骤的限制。

**具体怎么做**

MAGMA-GEN从当前策略自身产生的失败轨迹出发，让能访问额外状态信息的教练提出较早的决策错误假设及局部修正。由于教练也可能判断错误，系统不会直接把建议当作正确标签。它从同一状态、匹配条件下重新执行候选，只有确实改善后续进度的修正才被保留为恢复训练样本。这个反事实比较相当于检验“如果当时改成这样会不会更好”，使恢复监督建立在实际重执行结果上。

**结果能说明什么**

方法的可信依据是匹配条件下的重执行筛选，而非教练诊断必然正确；摘要报告仿真和实机收益，但未给出可通用于所有失败状态的恢复保证。

#### [FoldBack: Self-Correcting Masked Generative Policy for Long-Horizon Garment Folding](https://arxiv.org/abs/2610.10462)

**要解决什么问题**

折衣服时，一次漏抓或滑脱就可能使衣物没有到达计划中的形状。若长轨迹策略仍照原计划继续，后续动作会建立在错误状态上，导致失败进一步扩大。

**具体怎么做**

FoldBack把检查和轨迹细化安排在抓取、放置事件附近，以便在关键交互后验证是否成功。发现失败后，它让机器人退回可以重新抓取的位置，同时保留已经成功的抓取。随后只重新生成失败片段和选定的未来动作，并避开先前失败的抓取位置。这样，完整轨迹能够在执行中被局部修改，使系统先修复交互再继续，无需额外恢复示范或重新训练基础策略。

**结果能说明什么**

实机评估覆盖六类、33件衣物，75.2%是该设置下的最终折叠成功率；不应把无需恢复示范理解为任意任务都可直接使用同样恢复机制。

#### [Seeing is Believing: Certified Perception-Based Control from Learned Visual Representations via System Level Synthesis](https://roboticsconference.org/2026/program/papers/172/)

**要解决什么问题**

机器人只凭相机图像控制时，往往无法完整观察真实状态，还要面对传感噪声和非线性动力学。学到的视觉表示即使有助于控制，也未必能说明状态误差有多大，因此难以同时保证动作满足约束。

**具体怎么做**

方法先从预训练视觉特征学习低维观察表示，并为其建立随状态变化的误差界。控制器根据已有观察生成动作，使用随时间变化的仿射反馈形式，也就是让动作按观察的线性组合加偏置变化。作者通过系统级综合来优化这种因果反馈策略，再用逐次凸优化求解原本非凸的问题。视觉误差界进入控制设计，使系统能在考虑不确定性的同时主动获取信息，并约束后续运动。

**结果能说明什么**

约束认证依赖观察误差界和动力学等建模假设；仿真及地面车辆实机中未观察到违规，不能单独证明任意场景都安全。

### 人机与多机协作

多个机器人或人机共同工作时，问题不只是分别把动作做好，还包括理解对方意图、分工、同步，以及在信息有限时避免相互干扰。遥操作研究则关心如何让人用更少的操作负担控制复杂机器人。

方法包括推断人的目标与信任变化、用触觉或直观动作表达纠正意见，以及让机器人根据局部或稀疏共享信息协调。评估时除了任务成功，也需要看人的操作负担、沟通成本和协作是否稳定。

#### [Let the Body Follow: Coupled Egocentric Control for Whole-Body Robot Teleoperation](https://arxiv.org/abs/2607.16095)

**要解决什么问题**

全身遥操作要求操作者一边观察任务，一边协调机器人的头、手臂、躯干和移动底座。若躯干和底座的每次调整都要单独按键，操作者容易分心，手臂也可能伸到难以继续运动的位置。

**具体怎么做**

系统接收操作者的头部和手部运动，让机器人的身体自动配合这些主要操作。头部俯仰用于调整躯干高度，左右转头用于带动底座旋转；手的位置高度也参与调节躯干。当手臂末端接近可达空间的边缘时，底座自动平移，为手臂腾出继续操作的空间。这样，操作者可以主要关注看哪里、手往哪里走，把身体各部分之间的配合交给控制系统。

**结果能说明什么**

证据来自 TIAGo 移动操作机器人上的类居家照护任务和用户研究，支持操作效率与主观负担的改善；不能据此认定所有机器人构型和遥操作任务都同样受益。

#### [Learning Personalized Safety Interventions for Haptic Human-Robot Shared Control](https://arxiv.org/abs/2607.19534)

**要解决什么问题**

在人机共同控制机器人时，触觉反馈可以提醒操作者避开危险，但不同用户希望系统介入的时机和力度并不相同。预先写好的固定介入规则难以适应这些差异，逐项手动调参又需要反复试错。

**具体怎么做**

用户通过少量示范，教系统在遥操作过程中应当怎样给出触觉介入。系统使用一个基于控制屏障函数的优化层，把安全要求写成控制选择必须满足的约束；这一层可以求导，因此能根据示范反馈调整内部安全参数。学习目标是让生成的触觉响应接近用户示范的响应，而不是要求用户直接设置控制器参数。这把个性化需求转成可学习的交互行为，同时保留触觉共享控制的使用方式。

**结果能说明什么**

仿真和硬件实验支持少量示范下的偏好拟合，主要结果是生成反馈与示范之间的差距减小；摘要没有给出适用于任意用户或场景的安全保证。

#### [Belief-Aware Influence and Trust (BAIT): Shaping Human Belief During Repeated Human-Robot Interaction](https://arxiv.org/abs/2607.25327)

**要解决什么问题**

人在反复与机器人交互时，会根据机器人的行为改变自己的策略和对机器人的判断。把每次相遇当作独立事件会忽略这种积累，而靠难以预测的行为影响人又可能损害信任。

**具体怎么做**

BAIT 控制器把人的即时策略变化和较慢的认知变化分开估计。它用分层粒子滤波维护多种可能解释，并随着交互观察更新这些解释。规划器随后在这些估计基础上比较候选动作，权衡长期影响和人的信任，同时把当前任务表现作为必须满足的约束。这一设计让机器人在考虑对方未来反应时，也明确约束当下任务和行为可预测性之间的取舍。

**结果能说明什么**

证据覆盖仿真、用户研究和实车重复并线，支持相近任务表现下更高的用户信任；尚不能推广为其他长期人机关系中的普遍结论。

#### [RoboPrompt: Intuitive Robot Policy Steering with Sparse Human Input](https://arxiv.org/abs/2610.10534)

**要解决什么问题**

模仿学习策略遇到训练之外的情况时，常需要人来纠正，但专用遥操作设备和操作培训限制了使用范围。另一类方法需要修改或专门训练策略，才能让用户的简短提示影响动作。

**具体怎么做**

RoboPrompt 接收用户画出的轨迹、目标点或粗略方向，先用可复用模块把意图转成动作草稿。系统再利用基础策略原有的扩散或流匹配生成过程，逐步细化这些草稿；这两类过程都通过连续修正来生成动作。在生成过程的噪声空间中施加引导，使动作同时受到用户意图和策略已有经验的影响，初始引导阶段无需修改架构或专门微调。作者还把受引导的执行轨迹加入后续训练，使策略逐轮学习原先需要人工纠正的情况。

**结果能说明什么**

无需微调指初始引导阶段，后续用纠正轨迹改进策略仍涉及训练。摘要报告的成功率增幅未明确是相对百分比还是百分点，不能自行换算。

#### [Trend formation with sparse global sampling](https://arxiv.org/abs/2610.10521)

**要解决什么问题**

没有中央控制器、也不能密集交换全局信息时，机器人群体如何形成一致的运动秩序仍是难题。直觉上，观察更少同伴会增加误差，但这些误差究竟破坏还是帮助协调，需要明确分析。

**具体怎么做**

模型让每个运动个体定期随机抽取少量同伴，并朝这组同伴的质心调整方向，无需逐个读取邻居的位置和朝向。作者分析了这一转向规则如何把随机采样造成的误差转化为打破初始无序状态的因素。结果形成的是共同轴向的秩序，即个体沿同一条轴的两个方向排列，而不要求全部朝同一方向运动。论文进一步给出采样人数和采样频率决定能否形成秩序的判据，并用仿真和最多十五台机器人验证。

**结果能说明什么**

这种规则仍需要获取随机同伴子集的质心信息，不能理解为完全没有非局部信息。实验群体规模最多十五台，且共同轴向不等于同向航行。

### 效率与部署

一个策略即使动作正确，如果计算太慢、耗电太高，或者来不及吸收新观察，也无法可靠部署。本类研究关注感知、规划和动作生成整个流程中的时间与资源开销。

常见做法是复用相邻时刻的计算、只处理当前任务需要的信息，在简单状态使用快策略、困难状态再调用规划器，或减少生成动作所需的迭代。注意区分模型推断时间、收到新观察后的反应时间和任务总完成时间；它们不是同一个指标。

#### [Just-In-Time Scene Graph Growth: Combating Perceptual Saturation in Long-Horizon Robotics](https://arxiv.org/abs/2607.13245)

**要解决什么问题**

三维场景图把环境中的物体和关系组织起来，但先完整识别所有内容、再筛出任务相关部分会产生大量重复工作。长时间运行时，这些积累的观测和语义处理会拖慢算力有限的机器人。

**具体怎么做**

JITOMA 先根据当前任务生成关注区域，用它筛选持续进入的观测。系统只为环境保留低成本的基础锚点，也就是暂时不做详细理解的位置或对象线索。当任务查询到来时，语言模型解析机器人意图，只激活相关锚点及其局部关系，再执行详细物体描述等昂贵操作。通过把详细理解推迟到实际需要时进行，系统使活跃语义对象数量主要随当前任务需求变化。

**结果能说明什么**

低延迟和少量活跃对象的结果来自作者的 JITOMA-Bench；摘要中的每帧耗时不能直接视为任意硬件、环境和任务上的固定上界。

#### [JustDepth: Real-Time Radar-Camera Depth Estimation with Single-Scan LiDAR Supervision](https://arxiv.org/abs/2607.22172)

**要解决什么问题**

相机能提供丰富外观，却难以单独确定真实距离；车载雷达能测距，但返回点少且有噪声。把两者组合的现有流程往往包含多个阶段或依赖额外标注，增加了延迟和迁移成本。

**具体怎么做**

JustDepth 将相机图像和雷达数据输入单阶段深度估计器，训练时使用单次激光雷达扫描提供监督。它先把数量不定的雷达返回整理成固定宽度的一维表示，使处理量不再直接随点数变化。随后通过高度融合模块结合两种传感信息，再用轻量图神经网络在不同位置之间传递深度线索。训练时额外预测置信度以稳定学习，部署时去掉这一分支；数据增强则针对深度图中的条纹伪影。

**结果能说明什么**

保持精度、加速和减少条纹的对比结果来自 nuScenes；训练仍依赖激光雷达监督，不能理解为完全无需深度标注来源。

#### [Think Fast, Plan Selectively: Adaptive Deliberation for Efficient Data-Driven MPC](https://arxiv.org/html/2609.32591v1)

**要解决什么问题**

数据驱动的模型预测控制用学到的环境模型反复比较候选轨迹，但每一步都评估大量轨迹很耗时。即使机器人处在熟悉状态，也照常进行完整规划，会限制控制频率。

**具体怎么做**

Fast-TD-MPC 先用小型神经网络模仿原规划器的动作，得到可以快速执行的策略。它根据快策略运行时收集的内部状态，离线估计常见状态的分布，再衡量当前状态与该分布的距离；这里的距离会考虑各个方向的变化尺度。状态接近熟悉分布时直接使用快策略，偏离时切回原来的轨迹规划器。切回规划时还清除过期的上一轮候选解，从策略先验重新开始，避免沿用已经不适合当前状态的规划起点。

**结果能说明什么**

摘要报告在 103 个连续控制任务中保持有竞争力的表现，最高约四倍推理加速；这些结果不构成任意陌生状态下都能正确切换或恢复的保证。

#### [Muninn: Your Trajectory Diffusion Model But Faster](https://roboticsconference.org/2026/program/papers/160/)

**要解决什么问题**

扩散轨迹规划器通过反复去噪生成动作，但每一步都运行神经网络会使在线控制过慢。直接跳过计算或重复使用旧结果又可能改变最终轨迹，影响任务表现和安全相关指标。

**具体怎么做**

Muninn 给已有规划器加上一层缓存控制，无需重新训练模型。它先离线校准两种信息：内部轨迹表示变化的廉价探测信号，以及去噪误差如何传到采样更新中的解析系数。运行时由此估计复用旧去噪结果可能带来的最终轨迹偏差，并在整个生成过程中累计这笔偏差预算。预计偏差较小时复用缓存，预算不足或偏差较大时重新计算去噪器，从而把计算花在更有必要的步骤上。

**结果能说明什么**

论文的证书约束的是缓存结果与完整计算结果之间的距离，并依赖用户选定的容差和风险水平；它不保证完整计算策略本身在真实环境中安全。

#### [PathTime-VLA: Path-Time Decoupling for Factorized Post-Training of Vision-Language-Action Policies](https://arxiv.org/abs/2610.11771)

**要解决什么问题**

按固定时间间隔预测动作，会把机器人走哪条路径和走多快绑定在一起。遥操作示范中的停顿与快慢还受到接口延迟和操作者习惯影响，因而有用的几何指导会混入不理想的节奏。

**具体怎么做**

PathTime-VLA 用运动进度描述交互路径，再单独预测每段需要的正时间间隔，将路径映射成随时间执行的命令。对于同一条路径，系统可以改变时间安排而不改变几何学习目标。训练先用示范和人工纠正建立目标场景中的初始能力，再通过机器人交互学习速度倍率，并用执行结果继续调整路径生成器。最后由以路径为条件的动作模型落实运动，使路径和速度能够通过各自的学习环节改进。

**结果能说明什么**

三项任务中完整方法成功 58/60 次，固定速度对照成功 57/60 次，主要收益是成功试次平均完成时间缩短约 39%—52%。不能把这解释为成功率大幅提高，耗时统计也不包含失败试次。

### 本体与传感设计

有些能力限制来自硬件本身，例如相机看不到周围、触觉传感器只能测正压力，或机器人太宽而无法进入狭窄空间。本类研究通过改变机构和传感方式，让机器人获得原本难以实现的动作或观察。

方法包括利用身体运动扩大感知范围、把传感器分布到柔性结构上，以及通过机械结构把难测的信号转换成现有传感器能读到的变化。阅读时应同时看能力收益、制造复杂度、标定要求和实际原型验证。

飞行器在狭窄杂乱环境中飞行时，机载传感器视野有限，可能看不到周围障碍。让机体自行旋转可以扫到更多方向，但旋转速度又影响视野更新频率和飞行性能。

作者设计了一种持续被动自转的三旋翼飞行器，通过调整后臂构型选择自转工作状态。这样可以在机体设计层面调节感知覆盖更新速度与飞行性能之间的取舍。配套的分层规划与控制系统负责在持续旋转时保持自主飞行；执行航点巡检时，再通过重新规划引导点增加任务覆盖。方法把扩大视野的机械机制与适应旋转的控制系统一起设计，而非只增加感知处理。

真实实验覆盖高速跟踪、扰动抑制和杂乱环境导航，支持该构型的可行性；摘要没有给出可推广到其他机体的统一最优旋转速度。

#### [Towards Ultrafast Depth Sensing Via Active Event-based Stereo Vision](https://arxiv.org/abs/2607.23684)

传统主动双目系统用逐帧图像匹配深度，遇到快速运动时难兼顾速度、清晰度和稠密测量。事件相机只记录像素亮度变化，如何把这种异步信号与主动投影结合起来获得深度，需要新的硬件和算法配合。

**具体怎么做**

作者把两台事件相机与红外二维图案投影器组成主动双目原型，投影为场景提供可匹配的纹理。系统采集真实和合成的同步标注数据，用于训练从左右事件流估计视差的网络；视差就是同一位置在两台相机中的偏移，可用来计算深度。网络采用轻量模块，并用允许左右信号动态交互的匹配代价表示建立对应关系。它还利用事件流连续的时间线索约束结果一致性，以较低计算量输出稠密深度。

#### [TacGooseBumps (TacGB): Retrofitting Normal-Only Tactile Sensors with Shear Encoding for Learning Contact-Rich Manipulation](https://arxiv.org/abs/2609.34006)

**要解决什么问题**

插接件是否对齐、物体是否已经坐稳等接触状态，外观可能十分相似，却需要不同动作。只测垂直按压力的触觉传感器也可能漏掉横向摩擦和滑动线索，使策略难以判断。

**具体怎么做**

TacGooseBumps 在已有压力传感器表面加上一层带圆顶的被动薄膜。横向载荷使圆顶倾斜，并改变它下面的压力分布，把原来难以观察的切向接触编码成压力图中的图案变化。策略直接读取这些压力图并从示范中学习，无需增加电子器件，也无需先计算出准确的剪切力。其针对性在于提供能够重复区分接触状态的信号，而不是要求触觉系统完成精确测力。

### 评测与机制理解

论文报告的分数上升，到底说明机器人获得了什么能力？本类研究检查评价指标是否合理、对照是否公平，以及失败来自感知、规划、执行还是评测环境本身。

常见方法是保持其他条件不变，只改变一个因素；构造专门暴露记忆、恢复或损伤问题的任务；或从同一状态比较不同干预的后果。它们的价值在于帮助设计能区分原因的实验，而不只是给方法排出名次。

#### [REVERSAL-BENCH: A Reversibility Axis and Reset Oracle for Measuring the Reset-Free RL Cliff](https://arxiv.org/abs/2609.17745)

**要解决什么问题**

不依赖外部重置的强化学习，希望机器人能一直自主练习，但真实操作可能把物体推下桌或撒出颗粒，进入无法自行恢复的状态。若评测环境总能恢复，就难以判断方法究竟能否承受这种不可逆失败。

**具体怎么做**

REVERSAL-BENCH 用一个连续参数调节环境的可逆程度，并提供判断状态能否恢复的真值工具。作者在五种物理引擎、八类操作设置中比较普通强化学习、安全强化学习和专门的无重置方法。通过几何形状相同、可逆性不同的任务对照，研究把学习失败归因于不可逆性，而非单纯的障碍复杂度。论文还评估提前阻止危险转移的安全屏障，区分能预测陷阱和实际能避开陷阱这两种能力。

**结果能说明什么**

基准揭示了所测方法进入不可恢复状态后停止有效学习的现象，并未解决所有无重置训练问题。准确预测可恢复性，也不能让机器人从物理上无法恢复的状态中脱困。

#### [RESCUE: Is This Alarm Worth Acting On? Counterfactual Evaluation of VLA Runtime Monitors](https://arxiv.org/abs/2610.13516)

**要解决什么问题**

机器人失败监控器即使能准确报警，也可能报得太晚，已经没有挽救机会。误报还会打断原本能成功的执行，因此检测分数高不一定降低完成任务的总代价。

**具体怎么做**

RESCUE 在执行过程保存模拟器和策略状态，再从同一个检查点恢复出多条分支。各分支尝试继续执行或采用不同恢复动作，以比较如果当时采取另一种行动会怎样。系统据此寻找满足指定恢复标准的最晚检查点，并计算根据报警介入是否降低预期任务完成成本。这样，评测把报警时间、可用干预方式和误报代价联系起来，而非只统计成功与失败是否分对。

**结果能说明什么**

结果依赖具体策略、任务和干预方式，有些条件下恢复反而有害。理想检测器可容忍的 2.0%—3.3% 误报率来自所评估的停止并重置成本模型，不能作为所有部署的通用阈值。

#### [System Switch: When Should a Fast Decision Model Stop and Think?](https://arxiv.org/abs/2610.09683)

**要解决什么问题**

快策略需要在实时运行的环境中决定何时调用更慢的推理模型，但离线答题准确率不足以说明何时值得等待。模型自报的信心是否能识别错误，以及接管后能否持续推进任务，是不同的问题。

**具体怎么做**

作者在持续运行的 Doom 游戏中，让快模型承担日常决策，只在门控条件满足时转交给视觉语言推理模型。研究先比较快模型的正确率、信心是否准确，以及信心能否给正确与错误决策排序，再把低信心转交与随机转交对照。随后在闭环游戏中测试推理计划和固定探索规则，观察代理是否真的移动、开门并到达出口。通过这些分开设置的实验，论文检验离线选择性推理收益能否转化为实时任务进展。

**结果能说明什么**

闭环评测的所有变体都未到达出口，开门或离线答题改善不能当作完成任务。游戏结果也不能直接视为真实机器人上的验证。

#### [RoboQuest: Generalist Physical Agents that Search, Inspect and Test](https://arxiv.org/abs/2610.10388)

**要解决什么问题**

陌生环境中的任务信息常常不在当前画面里，代理必须先找物体、动手检查属性，或试用工具才知道下一步该做什么。即使基本操作能力已经具备，过早认定信息充分或忽略探索造成的扰动，也会使任务失败。

**具体怎么做**

RoboQuest 设计了十项移动操作任务，分别围绕搜索、通过操作检查和交互测试三类未知信息。代理需要主动获取证据、据此调整后续动作，并自己决定何时结束探索、执行任务目标。作者用同一视觉动作接口比较五个多模态代理及一个用完整示范微调的策略，再在直接给出隐藏信息的条件下单独测试基本技能。后一项对照用于判断失败主要来自执行困难，还是来自没有正确寻找和使用证据。

**结果能说明什么**

最佳代理 23% 的成功率和微调策略几乎不成功，针对的是完整未知信息任务；不能据此说代理不会执行其中的全部基本动作。摘要未明确全部任务的实机与仿真层级。

#### [OopsieVerse: A Safety Benchmark with Damage-Aware Simulation for Robot Manipulation](https://arxiv.org/abs/2606.31993)

**要解决什么问题**

家务机器人完成任务时仍可能撞坏物品、造成热损伤或引发液体相关损坏，仅看成功率会漏掉这些后果。现有仿真通常缺少统一表达和计量损伤的机制，因而也难用它训练更安全的行为。

**具体怎么做**

OopsieVerse 把接触力、温度变化和液体交互转换为机械、热或流体损伤，使损伤成为可单独记录的任务信号。其 DamageSim 层负责检测和计量损伤，并在两种不同物理后端的模拟器中实现。配套家务任务同时考察是否完成目标和是否造成伤害，避免把两者混为一个结果。作者进一步用实时损伤反馈指导示范采集，并用损伤信息训练策略、比较现有策略和考察仿真到真实的迁移。

**结果能说明什么**

损伤判定依赖所建模的机制和参数，不能认为覆盖全部真实损坏形式。仿真指标改善与真实安全之间仍需具体迁移实验支持。

## 交叉观察与后续阅读

从本轮摘要级研究版图观察，数据问题至少包含采集成本、动作或触觉标注缺失、外部数据的任务相关性三层。减少示教条数的证据需要同时检查已有预训练数据、仿真生成数据和人工筛选成本；这些路线不能直接换算为 Carrot 所需的采集小时数。

世界模型的表示质量、预测误差、规划代价和闭环成功是不同环节。部分诊断工作发现，预测能力充分时，目标距离的几何或可达性失真仍可能限制规划；也有工作把预训练特征与对象表示本身的贡献拆开。地图应保留这些可检验的问题，而不将世界模型归成单一解决路线。

运行时读出进度、检测失败和执行恢复是三个不同问题。[RESCUE](https://arxiv.org/abs/2610.13516)恢复同一模拟器与策略检查点，对比不同干预分支，说明高检测分数未必降低任务完成成本；恢复还可能破坏原本能成功的执行。其误报预算结论依特定停机重置成本模型，不能直接套用实机。离线轨迹误差下降同样不等于真实闭环更安全。

完成任务、遵守指令、真正利用记忆和避免损伤不能用同一个成功率代替。[FindingDory](https://eccv.ecva.net/virtual/2026/poster/4986)要求记忆对行动确实必要；[BeTTER](https://eccv.ecva.net/virtual/2026/poster/5364)隔离运动学因素后干预推理；[ICBench](https://eccv.ecva.net/virtual/2026/poster/5241)保持场景不变而改变指令；[OopsieVerse](https://arxiv.org/abs/2606.31993)把损伤作为显式物理信号。这些工作提供可区分失败原因的实验设计，而非直接证明某类架构优越。

部署效率也应区分计算时延与环境变化后的反应时延。[FASTER](https://neurips.cc/virtual/2026/poster/156001)优先生成近期动作，并分析首动作时延和执行时域；[Fast-WAM](https://neurips.cc/virtual/2026/poster/149922)用受控变体区分训练期视频建模与推断期未来生成的贡献。这提供了两个独立研究问题：策略何时吸收新观察，以及为当前动作到底需要计算哪些未来信息。所报收益限作者评测设置。
