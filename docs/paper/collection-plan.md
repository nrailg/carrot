## 完成标准

1. cs.RO 主池在本次 API 查询快照内可核验完整；跨分类补查明确查询覆盖边界。
2. 九个会议都有处理结论。获取不到完整官方目录时，必须保留缺口与降级证据，不能以二手目录代替官方确认。
3. 来源之间不直接累加为唯一论文总数；跨来源关联采用保守规则。
4. 所有纳入条目可追溯到论文链接或明确标注的候选来源；不根据标题编造实验结论。
5. 这轮不逐篇精读，不判断适合 Carrot 的最终研究方向，不开展实验。

## 范围边界

主要会议：机器人专门会议尽量全收；综合会议扫描完整目录后筛选相关候选。时间窗外的会议不整体并入近三个月主池；未来会议的已公开条目单列补充。

本轮不系统穷举 RAL、T-RO、IJRR 等期刊，不系统穷举 HRI、Humanoids、ISER 等专项会议，也不穷举所有 workshop。此项是本轮范围边界，不表示这些来源不重要。
